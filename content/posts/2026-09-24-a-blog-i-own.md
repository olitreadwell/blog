I have wanted a place to write that is not a social network for a while. This
is it. Posts, notes, links and photos all live in one stream, and every one of
them is a markdown file in a git repository.

The format matters more than the tooling. Markdown in git means the writing
outlives whatever generator builds the site, and it means an agent can read and
write the content without a database in the way.

Short notes belong here too. A thought that takes two lines should not need a
title, a slug and a publish dialog.
